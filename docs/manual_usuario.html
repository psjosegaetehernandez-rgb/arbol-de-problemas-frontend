Manual de Usuario

Bienvenido/a a Árbol de Problemas, la plataforma segura para la gestión de casos de la Red Nacional.

⚠️ Regla de Oro de Seguridad: Esta plataforma no tiene "recuperación de contraseña". Si pierdes el Token de un caso o la contraseña de tu respaldo, la información se perderá irremediablemente. Así proteges a las personas.

1. Crear un Caso Nuevo

  1. Ve a "Mis casos" y presiona el botón "+ Nuevo caso demo".
  2. Llena el formulario (los datos se cifrarán automáticamente).
  3. Al guardar, el sistema te llevará a la carpeta del caso, la cual estará bloqueada.

2. Abrir la Bóveda (Token)

  1. Cuando abras un caso, verás un candado amarillo.
  2. Ingresa el Token de seguridad. Para los casos nuevos en esta demo, el token por defecto es 1234.
  3. Haz clic en "Desbloquear Carpeta". Ahora puedes leer y editar la ficha.

3. Adjuntar Documentos

  1. Dentro de la carpeta desbloqueada, ve a la pestaña "Documentos".
  2. Haz clic en "+ Adjuntar Documento" y selecciona una foto o PDF.
  3. El archivo se cifrará en tu dispositivo antes de guardarse (verás el ícono 🔒).

4. Exportar PDF Seguro

  1. En la pestaña "Ficha del Caso", presiona "📄 Exportar PDF".
  2. Se descargará un documento oficial con la información descifrada. Úsalo solo para imprimir y no lo compartas por redes.

5. Respaldos Cifrados (¡Vital!)

  1. Ve a la pestaña "Configuración" en el menú lateral.
  2. Presiona "🔒 Exportar Respaldo". Se te pedirá crear una contraseña (guárdala muy bien).
  3. Se descargará un archivo .json.enc. Guárdalo en un pendrive.
  4. Si cambias de computadora, usa "🔓 Importar Respaldo" en la nueva PC, sube el archivo y pon la contraseña.

6. Incidencia Política (Informes y Red)

  • Informes: Genera un PDF mensual con las estadísticas agrupadas (K-Anonimato) para presentar a autoridades.
  • Estadísticas: Al presionar "Sincronizar a la Nube" dentro de un caso, los metadatos anónimos suben a este panel para comparar regiones sin exponer a las personas.
