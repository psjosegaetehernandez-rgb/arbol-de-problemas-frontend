2. Características de Seguridad

  • Zero-Knowledge: El servidor (o base de datos central) nunca ve los datos en texto plano.
  • Cifrado E2EE: Los casos se cifran con AES-256-GCM en la memoria del dispositivo antes de guardarse.
  • Control de Acceso (CapBAC): Acceso a carpetas por medio de Tokens (contraseñas maestras por caso).
  • K-Anonimato (k=5): Las estadísticas ocultan números menores a 5 para proteger identidades en zonas pequeñas.
  • Offline-First: La aplicación funciona sin internet y guarda todo localmente de forma segura.

3. Módulos Implementados

  1. Panel General: Dashboard de métricas con protección K-Anonimato.
  2. Mis Casos: Lista de casos y apertura de bóvedas cifradas.
  3. Carpeta del Caso: Ficha cifrada, gestión de documentos cifrados y exportación de PDF seguro.
  4. Accesos: Generador de tokens (llaves) para asignar casos a voluntarios.
  5. Informes: Generación de PDF ejecutivos para incidencia política (con datos agrupados).
  6. Configuración: Exportación e importación de respaldos cifrados (.json.enc).
  7. Red Nacional (Estadísticas): Vista agregada simulando la recepción de datos de múltiples organizaciones.
